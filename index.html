01 / SOBRE O PROJETO

Uma visão mais clara
da operação de vendas.

Este projeto de Business Intelligence explora uma base fictícia com 900 registros de vendas referentes a 2025. A proposta é organizar os dados e transformá-los em informações que ajudem a compreender o desempenho comercial.

A análise considera diferentes perspectivas — tempo, produtos, categorias, regiões, canais e vendedores — para estruturar uma leitura completa dos resultados e apoiar decisões baseadas em dados.

i

Sobre os números: os dados de volume e período acima são informações confirmadas do projeto. Os gráficos desta página são elementos visuais conceituais, não resultados calculados. Os indicadores acima são campos editáveis: atualize os valores no arquivo dados.js do repositório GitHub. Eles começam como “Preencher” para evitar números fictícios.
