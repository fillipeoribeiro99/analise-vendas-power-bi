# Análise de Vendas e Performance Comercial

Projeto de análise de dados desenvolvido com foco em Business Intelligence, utilizando uma base de vendas fictícia para explorar indicadores comerciais e identificar padrões de desempenho.

## Sobre o projeto

O projeto tem como objetivo analisar o desempenho comercial de uma empresa fictícia, considerando informações de vendas, produtos, regiões, vendedores e canais de comercialização.

A proposta é transformar os dados em informações visuais que facilitem o acompanhamento dos resultados e apoiem a tomada de decisões.

## Ferramentas utilizadas

- Power BI
- Power Query
- DAX
- CSV

## Análises

- Faturamento e lucro ao longo do tempo.
- Desempenho por produto e categoria.
- Comparação de resultados entre regiões.
- Desempenho dos vendedores.
- Análise dos canais de venda.
- Margem de lucro e ticket médio.

## Base de dados

A base utilizada contém 900 registros fictícios de vendas referentes ao ano de 2025. Os dados foram gerados para fins de estudo e desenvolvimento do projeto.
