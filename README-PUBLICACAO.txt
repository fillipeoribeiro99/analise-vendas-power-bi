ATUALIZAR OS INDICADORES DO SITE

1. Abra o repositório no GitHub.
2. Clique no arquivo dados.js.
3. Clique no lápis (Edit this file).
4. Substitua os textos "Preencher" pelos seus valores reais.
   Exemplo: faturamento: "R$ 125.430,00"
5. Clique em Commit changes.
6. Se o Netlify estiver conectado ao GitHub, o site será atualizado automaticamente.

CAMPOS DISPONÍVEIS
- faturamento: faturamento total
- lucro: lucro total
- quantidadeVendas: número de vendas
- ticketMedio: valor médio por venda

IMPORTANTE
Os campos começam como "Preencher" para não exibir números inventados.
O arquivo dados.js concentra os valores que você pode trocar diretamente pelo GitHub.
O ZIP contém os arquivos do site; ele ainda precisa ser enviado/atualizado no repositório para substituir a versão publicada.
